# Jogo da Forca

Projeto-modelo da disciplina: jogo da forca no navegador (JavaScript + canvas), construído por issues pequenas com apoio de um agente de código.

- Especificação: `docs/ESPECIFICACAO.md` · Arquitetura: `docs/ARQUITETURA.md` · Tarefas: Issues (épico #1).
- Instruções do agente: `.github/copilot-instructions.md`.

## Comandos

```
npm ci            # instala as dependências
npm run dev       # servidor local em http://localhost:8000
npm test          # testes (node --test)
npm run check     # ESLint + Prettier + testes: o que o CI roda
```
